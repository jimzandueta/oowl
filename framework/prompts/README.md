# Prompt Library

Prompt files are grouped by the kind of rule they enforce.

## Groups

- `workflow/` - routing, approval gates, protocols, protected artifacts, Git handoff, parallel build, verification.
- `execution/` - cost tiering, implementation safety, low-tier limits, sensitive-data routing.
- `methodology/` - Superpowers and Caveman usage policy.
- `runtime/` - model mapping and generated model strategy.
- `engineering/` - architecture, code conventions, file structure, tool preferences, and error handling.
- `review/` - plan completeness and security review checklists.

## Rules

- Do not add new prompt files at the root unless they are this index.
- Do not recreate `shared/`; choose the specific group instead.
- Keep prompt references category-qualified, for example `workflow/protocols.md`.
- `runtime/model-strategy.md` is generated by `scripts/apply-profile-models.sh`; do not edit it directly.
